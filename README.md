# 🎲 Dicee Game

A sleek, responsive, modern two-player dice rolling web application. Built with semantic HTML5, CSS Flexbox with fluid typography, and clean ES6+ JavaScript.

---

## 📸 Overview

Dicee is a lightweight web game where two players roll a die on every page refresh to determine the winner. The project was engineered with accessibility, performance, and clean code principles in mind.

---

## ✨ Features

* **Responsive Design:** Seamlessly scales across mobile, tablet, and desktop screens using modern CSS `clamp()` typography and Flexbox.
* **Semantic & Accessible:** Utilizes HTML5 semantic landmarks (`<main>`, `<section>`) and dynamic `alt` tags for screen readers.
* **Modern JavaScript (ES6+):** Modular helper functions, arrow functions, and secure DOM manipulation (`textContent`).
* **Optimized Performance:** Preconnected Google Fonts and deferred JavaScript loading to eliminate render-blocking.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic structure and accessibility (ARIA).
* **CSS3:** Custom properties (CSS variables), Flexbox, fluid responsive sizing.
* **JavaScript:** ES6+, DOM manipulation.
